# Cedar Market demo site

Fictional, static retail demo for Krishna's FDE lab. Includes policy FAQs, three fictional bouquets and an accessible flower request builder. The builder calculates illustrative totals and prepares a prompt to copy into the lab AI agent. It does not submit orders, collect personal information, take payments, or call MCP from the public browser. Livechat remains pending.

Catalog: Cedar Bloom $35, Rose Garden $55, Sunny Day $45 USD; quantities 1–5; pickup free, simulated delivery $7. Destination aliases are demo-home, demo-office and demo-store. The private authenticated flower MCP must quote and confirm the actual synthetic order. No secrets belong in this public repository.

Open index.html to preview. app.js requires no build system. The planned Webex Connect Livechat widget requires a separately provisioned digital channel, disclosure and approved domain. Google Fonts are optional external assets.
