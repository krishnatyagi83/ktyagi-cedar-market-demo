# Cedar Market demo site

Fictional, static retail demo for Krishna's FDE lab. The FAQs mirror the fictional lab knowledge. There is no live ordering, chatbot, contact form, tracking, credential, or Webex connection. Do not add secrets. The planned Webex Livechat widget requires a separately provisioned digital channel and approved site domain.

Open `index.html` directly to preview. Publish the contents as static files. Google Fonts are optional external assets; the page falls back to system fonts if unavailable.
